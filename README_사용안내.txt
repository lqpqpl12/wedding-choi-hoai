최준환 · 팜 티 호아이 모바일 청첩장

예식은 2027년 1월 17일 일요일 오후 5시, 베트남 현지시간(UTC+7)입니다.
장소는 Summer Vinh Convention Center입니다.
주소는 343 Lê Duẩn, Phường Trường Vinh, Nghệ An, Việt Nam입니다.
지도 링크  https://maps.app.goo.gl/mGPciXCmSryP45Ct9?g_st=ac

미리보기
ZIP을 모두 풀고 index.html을 브라우저로 엽니다. assets 폴더와 wedding.ics를 같은 위치에 둡니다. 초대글과 원본 웨딩 사진 10장을 오프라인에서도 볼 수 있습니다. 지도와 구글 캘린더는 인터넷 연결이 필요합니다.

GitHub Pages
lqpqpl12/wedding-choi-hoai 저장소의 main 브랜치 루트에 압축을 푼 파일과 폴더를 올립니다. Pages의 배포 소스는 Deploy from a branch, main, /(root)입니다. 설정된 공유 주소는 https://lqpqpl12.github.io/wedding-choi-hoai/ 입니다. 서버 공개 후 이 주소를 카카오톡에 붙여 넣거나 청첩장 하단의 ‘청첩장 공유’를 누릅니다. 링크 미리보기는 index.html의 Open Graph 정보와 assets/share.jpg를 사용합니다.

계좌정보 수정
index.html 하단 CONFIG의 groomAccount(신랑 측), brideAccount(신부 측)에 은행명, 계좌번호, 예금주를 작은따옴표로 묶어 입력합니다. 입력할 계좌가 없는 쪽은 null로 둡니다. 둘 다 null이면 ‘계좌정보는 추후 안내해 드리겠습니다.’라고 표시됩니다. 입력 후 다시 게시하면 반영됩니다. 계좌정보는 청첩장 및 공개 소스에서 열람할 수 있습니다.

달력과 일정
D-day는 베트남의 달력 날짜를 따릅니다. 구글 캘린더와 wedding.ics의 시작 시각은 베트남 오후 5시, 한국 오후 7시이며 저장 구간은 기존 설정대로 1시간입니다. 휴대전화의 달력에는 해당 기기에 설정한 시간대로 표시될 수 있습니다.
